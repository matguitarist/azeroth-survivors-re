**Faster first download, presets, and a launcher that notices a stuck start.**

- **Faster game data download:** three files at once (archive.org paces each connection), with one combined progress line, a progress bar on the Dock icon, and a notification when it's done.
- **Graphics presets:** Performance, Balanced and Quality in Settings → Graphics. Quality leaves anti-aliasing off: on an M4 at 4K, 4× MSAA alone took the game from about 113 fps to under 60.
- **Stuck start detection:** if the game hasn't opened its window after 25 seconds (usually an audio output device that isn't answering, such as a remote-desktop driver), the launcher offers Keep Waiting or Force Quit.
- Update versions now come from the release number, so updates always arrive in order.

Already on 0.2.0? The app offers this update by itself, or use Azeroth Survivors → Check for Updates….
