**Smoother frames, cleaner edges, quest markers, and a home server that backs itself up and updates itself.**

- **Max frame rate:** cap the game at 30, 60 or 120 fps (Settings › Graphics, or the in-game settings), and at 30 while it is in the background. With vertical sync off it saves battery and heat without tearing through frames the display never shows.
- **Edge smoothing (SMAA):** smooths jagged edges, leaves and grass included, for almost no cost; it can be switched while playing.
- **Dynamic resolution:** when the graphics can't keep up with your frame rate, the 3D drops its resolution a little and climbs back once things calm down. If dropping doesn't help (as on most Apple-silicon Macs with MetalFX), it steps aside by itself.
- **Faster big Survivors fights:** the floating combat text of huge crowds costs a fraction of what it did.
- **Quest markers (AzerothPlus):** your quests' objectives and where to turn them in, on the world map and the minimap.
- **Home server backups:** accounts and characters are saved every night (the last 14 kept, on Unraid's array), with Back Up Now and Restore in Settings › Home Server. A restore saves the current state first.
- **Home server updates:** Check for Updates compares the server with the newest CMaNGOS, playerbots and world database; Update Server… rebuilds it on the server, keeps every account and character, and puts the old server back if anything fails.

These graphics settings work in Survivors and Classic alike. Already on 0.6.1? The app offers this update by itself, or use Azeroth Survivors → Check for Updates….
