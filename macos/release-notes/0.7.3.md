**A dashboard for your home server, on every screen in the house.**

- **Home server dashboard:** open http://(your server's address):8095 in any browser at home (a phone, a tablet, another computer) to see whether the server runs, who's playing, the bots online by level, CPU and memory with 24-hour charts, the latest backups, the server's settings and software, and its latest real errors. It updates every minute, stays up while the game is stopped, and is reachable only on your home network. The launcher sets it up by itself the next time it connects.
- **Right now:** Settings › Home Server shows the same live: who's playing, bots online, what the game server takes, free memory, uptime and the last backup, with Open Dashboard. The Server menu opens it too.
- **Quieter logs:** bots that find no spot near the players stay where they are; the Logs window counts those messages with the other harmless bot lines, not as errors.

Already on 0.7.2? The app offers this update by itself, or use Azeroth Survivors → Check for Updates….
